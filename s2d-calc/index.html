How the result is calculated

Follow the record limit through to the usable volume size.

  1. 01

    Record capacity

    4 MiB / 64 bytes / 2 = 32,768 records

  2. 02

    Effective node count

    4 selected nodes = 4 effective nodes

  3. 03

    Base record-limit formula

    32,768 x 4 x 1 GiB / 6 = 21.33 TB

  4. 04

    Usable volume size

    21.33 TB - 0.5 TB overhead = 20.83 TB
